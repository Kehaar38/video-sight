## ブロック別レビュー

### XIAO / IDC / LCD周り

左上にXIAOブレイクアウト用IDCコネクタ `J2` とLCDヘッダ `J3` がまとまっている。LCDとXIAO間の配線が短く、テストボードとして良い。

確認したい点:

- `J2` のpin 1マーク、キー溝方向、ケーブル出口方向。
- ブレイクアウト基板側とストレートIDCケーブルで `pin N -> pin N` になること。
- LCDケーブルは逆挿し可能なので、少なくともpin 1側/向きのシルクを強くすること。

### 電源周り

左側にBattery, SW_BATT, AO3401A, BATT_CURRENT, TPS22919周辺がまとまっている。テストポイントも近く、測定しやすい。

良い点:

- `BAT+`, `BAT_SW`, `XIAO_BAT`, `XIAO_3V3`, `PERIPH_EN`, `PERIPH_3V3` が測りやすい。
- TPS22919周りのC1/C2/C3/C4が近く、意図が追いやすい。
- Q1 AO3401AとR1が近い。

確認したい点:

- Q1 AO3401AのSOT-23 pin 1向きと、実部品マーキング。
- TPS22919カスタムフットプリント `@自分用:DCK0006A_L` のpin 1位置とパッド番号。
- C3/C4が極性付き部品なら、シルクの `+`/`-` が実装時に十分分かるか。
- 電源系の配線幅が発注前の想定電流に対して十分か。

### BNO055周り

BNO055モジュールは左下寄りに配置され、近くに `RESET`, `INT`, `GND`, `2V8_OUT` のTPがある。bring-upでは扱いやすい。

確認したい点:

- BNO055モジュールの実物を挿した時、部品や周囲TPと干渉しないか。
- `2V8_OUT` は観測用で、給電入力に見えないようにする。
- IMUとして使うなら、最終筐体では周囲磁性体/電流経路との距離に注意する。今回のテストボードでは検証用として問題ない。

### ATtiny1616 / 入力装置周り

右側に入力ボタン、ロータリーエンコーダ、ATtiny1616、UPDI、VCCジャンパがまとまっている。サブMCU入力系のテストボードとして分かりやすい。

良い点:

- ATtinyの左右ヘッダがあり、実験・ジャンパがしやすい。
- UPDIヘッダと `ATTINY_VCC` ジャンパが近い。
- C8がATtiny VCC側にあり、以前の方針通り。
- WAKEボタンが追加されている。

確認したい点:

- SW3/SW4/SW5/SW6/SW7を実際に指で押した時、周囲コネクタや筐体と干渉しないか。
- ロータリーエンコーダSW7のノブ径、軸高、取り付けナット/ワッシャのクリアランス。
- J8とSW7の近さ。ケーブルを挿した状態でエンコーダ操作に支障がないか。

## 目視で気になった点

### 1. J2 IDCとLCDの向き表示

DRCでは見つからないが、実機で一番怖いのはコネクタ向き。

推奨:

```text
J2: pin 1、キー溝、ケーブル出口方向をシルクで明示
J3: LCD pin 1 / VCC / GND側をシルクで明示
```

### 2. 実装時のシルク重なり

全体的に見やすいが、部品密集部では実装後に隠れる文字がある。特にU1/TPS22919周辺、C3/C4周辺、J3/J2周辺は、組み立て後に値よりもネット名/向きが分かる方を優先したい。

### 3. GNDプレーンの分断

スクリーンショットでは中央〜右側に長めの配線があり、GNDゾーンが一部細く分断される可能性がある。DRCは通っているが、発注前にKiCadのゾーン塗りつぶし後表示で、GNDが島になっていないか確認する。

推奨:

```text
- GNDゾーンを再塗りつぶし
- unconnected island削除/確認
- GNDビアを必要に応じて追加
- LCD/SPI、ATtiny、電源周りの近くにGND returnがあるか確認
```

### 4. 電源配線幅

画像上では細すぎるようには見えないが、`BAT+`, `BAT_SW`, `XIAO_BAT`, `XIAO_3V3`, `PERIPH_3V3` は、信号線より太めにしておくのが安全。

特にLCDバックライトや周辺電源の瞬間電流を考え、電源経路は発注前にネットハイライトして確認する。

### 5. マウント穴と筐体

四隅のM3穴は良い。発注前に以下を確認する:

```text
- ネジ頭/スペーサが部品と干渉しないか
- 銅箔/シルク/配線が穴周辺に近すぎないか
- 将来の仮筐体で固定しやすい位置か
```
