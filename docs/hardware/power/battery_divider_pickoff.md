# VIDEO SIGHT バッテリー分圧取り出し位置

対象経路:

```text
18650 -- (A) -- SW -- (B) -- AO3401A -- (C) -- XIAO BAT
```

## 判断

バッテリー分圧は `(C)` から取る。

理由:

- ファームが読みたいのは、実際にXIAOへ届いている電源電圧。
- SW OFF時はXIAOもOFFなので測定不要。Cから取れば分圧抵抗の常時消費も切れる。
- AO3401Aの電圧降下込みで、実際のシステム電圧を監視できる。
- 逆接時にADC/分圧回路もQ1の保護下に入る。

## A/B/C比較

### A: 電池直後

利点:

- 純粋なセル電圧を測れる。

欠点:

- 物理SW OFFでも分圧抵抗が電池に常時接続される。
- 逆接保護の外側になる。
- XIAOがOFFの時に測っても使い道が少ない。

### B: SW後、AO3401A前

利点:

- SW OFF時には分圧消費が切れる。

欠点:

- 逆接保護の前段なので、ADC/分圧が保護外になる。
- AO3401Aの電圧降下を含まない。

### C: AO3401A後、XIAO BAT側

利点:

- SW OFF時に分圧消費が切れる。
- 逆接保護後なので安全。
- XIAOへ実際に入る電圧を測れる。
- ADC入力保護として自然。

欠点:

- AO3401Aの電圧降下後の値になる。ただし通常負荷では数十mV以下で、実用上は問題になりにくい。

## 結論

```text
18650 -- SW -- AO3401A -- (C) -- XIAO BAT
                         └─ 470kΩ/220kΩ分圧 → D3/GPIO4 ADC
```

C点から分圧し、分圧下側はGNDへ接続する。
