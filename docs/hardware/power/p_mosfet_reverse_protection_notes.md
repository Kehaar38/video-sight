# VIDEO SIGHT P-MOSFET逆接保護メモ

## 選定条件

1セルLi-ion/18650の入口逆接保護用。

- P-channel MOSFET
- VDS定格: 20V以上あれば十分、30V品なら余裕
- RDS(on): VGS=-2.5Vまたは-4.5Vで低いこと。目安100mΩ以下、できれば70mΩ以下
- ID: 連続1A以上、できれば2〜3A級
- VGS(max): ±12Vまたは±20V。1セルLi-ionでは通常問題なし
- パッケージ: SOT-23等のリード付きSMDが扱いやすい。真のDIP/TO-92品は低RDS品が少ない

## 定番候補

- AO3401A / 互換品
  - P-ch, 30V, SOT-23系。安価で入手性が高く、1セル機器の逆接保護でよく使われる。
  - クローン/互換品が多いので、可能ならメーカー品または信頼できる販売店から買う。
- IRLML6402
  - P-ch, 20V, SOT-23系。ロジックレベル寄りで低電圧用途に使いやすい。
- DMP3098L
  - Diodes Inc.のP-ch, 30V, SOT-23系。メーカー品として選びやすい。
- DMG2305UX等
  - Diodes Inc.の小型P-ch候補。低RDSで入手できる場合は良い。

## 回路案

物理スイッチOFFで完全に電池を切りたいなら、スイッチはできればP-MOSFET前段に置く。

```text
保護回路付き18650 +
  ↓
物理電源スイッチ
  ↓
P-MOSFET drain
P-MOSFET source
  ↓
XIAO BAT+
```

P-MOSFETのゲートはGNDへ高抵抗で落とす。

```text
Gate ─ 1MΩ程度 ─ GND
```

Li-ion 1セルではVGSが最大でも約-4.2Vなので、通常はゲート保護ツェナーは不要。ただし長い配線や静電気が気になるなら保護部品を検討する。

## 向き

P-MOSFETのボディダイオードが、正しい極性で一瞬だけ入力から出力へ流れる向きにする。

一般的には:

```text
Drain  = バッテリー/スイッチ側
Source = XIAO BAT側
Gate   = GNDへ抵抗
```

正接続時はボディダイオード経由でSource側が上がり、その後 VGS<0 になってMOSFETがONする。逆接続時はボディダイオードが遮断方向になり、負荷側を守る。

## 抵抗値

- Gate-GND: 1MΩ程度を推奨。4.2V時の常時消費は約4.2µA。
- 100kΩでも動作は堅いが、物理OFF時にこの抵抗が電池へ残る配置だと約42µAを消費する。
- 物理スイッチをMOSFET前段に置けば、OFF時はこの消費も切れる。

## 決定

VIDEO SIGHTでは `AO3401A` を採用する。Digi-Keyで購入するため、互換品/クローンではなく信頼できるメーカー品として扱う。

実装方針:

- パッケージはSOT-23想定。
- PCBAは使わず自分ではんだ付けする。
- SOT-23程度は手実装可能な前提。
- 基板はユニバーサル基板ではなくKiCadで設計し、JLCPCBへ発注する。
- まずテスト用の大きめ基板、その後に筐体組み込み用の本番基板の2段階で作る。

注意:

- AO3401AのSOT-23フットプリントはメーカー推奨ランドまたはJLCPCBで一般的なSOT-23-3ランドを使う。
- Drain/Source/Gateのピン番号をKiCadシンボルと実データシートで必ず照合する。
- 逆接保護ではDrain=バッテリー/スイッチ側、Source=XIAO BAT側、Gate=GNDへ抵抗の向きで確認する。
